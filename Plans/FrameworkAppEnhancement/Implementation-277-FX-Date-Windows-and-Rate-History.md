## Implementation and evidence checkpoint

Its nullable, null-omitted property on the existing review preserves original whole-pair serialization and hashes. New posting sources query their exact calendar date; management reviews query the proposed effective interval. The validated source digest includes the scope, and creation must match the reviewed interval exactly.

The existing native GL/book owner uses Beep AppFilter comparisons on EFFECTIVE_FROM and EFFECTIVE_THROUGH plus original company/book/source-currency/active constraints. Every returned record must satisfy the requested window; incorrect provider predicates, unknown book/currency/company, inverted scopes, overlaps and unavailable dates are refused. Initial/closing native books, schema, datasource and authority remain checked. The record-count bound applies to the selected window rather than accumulated history.

Inside the existing owned Serializable PRODUCTION transaction, version reservation is queried independently across the company/book/source-currency pair without date or active filters. Global UUID/intent reservations remain independent. New creation checks the original complete interval before insertion, exact native read-back, unchanged other interval facts and closing version reservation; an externally added reservation outside the window rolls back the insertion. Known retry confirms only the original version/command without another write. No historical quote is deleted or silently replaced.

The existing API/client and Mud form add explicit proposed interval review. The administrator selects the start and through dates before reviewing authority; the resulting interval is displayed and frozen for creation. Source currency and date changes invalidate displayed evidence and fence late results. Read-only users still query explicit dates and recover their own original commands. Single-day and multi-day forms preserve the exact request through lost follow-up, detach/recreation and management-permission removal. Historical posted conversion evidence and private producer recovery remain intact. Real source or authority changes still refuse continuation.
