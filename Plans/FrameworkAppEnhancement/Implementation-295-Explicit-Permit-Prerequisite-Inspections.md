In progress; continues [293](Implementation-293-Independent-Permit-Review-and-Approval.md) and [294](Implementation-294-Durable-Permit-Rejection-and-Recovery.md). Extends the existing inspection owner and screens to supply explicit, versioned acceptance evidence for reported permit references. Material inventory quantity/unit/allocation/availability remains a separate required source and still blocks approval. Reported references alone establish no readiness.

Canonical Data adds nullable PERMIT_PREREQUISITE_KIND to the existing WORK_ORDER_INSPECTION, and the same optional field to its existing request/projection. Only explicit ISOLATION, RISK, PERSONNEL and MATERIAL labels are accepted, with a reference and PRE_START/SCE_VERIFY category. Generic inspections retain their original JSON/revision shape when the label is absent. The existing explicit PPDM_CORE Beep manifest owns this nullable column evolution; no migration is applied, and no SQL or business EF lane is added.

API registration uses the actual selected app account and standard roles with HSE.ApprovePermit; the existing direct FIELD/order WRITE boundary also remains required. IdentityServer remains authentication-only. Generic inspection behavior is preserved.

The existing inspection state freezes the label in the original command, requires the current selected app permission for specialized actions and rejects changed readback. Its MudBlazor panel shows the recorded label, provides an optional explicit label selector only for permitted users and requires a reference for labeled requirements. Recorded results remain immutable; corrections need their existing reviewed audit workflow.

The canonical prerequisite evidence projection compares explicit kind, original reported reference and jurisdiction against the complete current order/FIELD inspection snapshot. Exactly one matching PASS from a different inspector than the permit issuer, with evidence time no later than comparison UTC, establishes recorded inspection acceptance. Unlabelled, mismatched, ambiguous, unaccepted, issuer-owned or future evidence remains explicit. The reviewer screen shows kind/reference, actual inspection identity, inspector and acceptance state. Material inspection acceptance does not prove physical stock or allocation.

New native independent reviews use explicit prerequisite evidence policy version 1. Historical reviews omit the default version and keep version 0's exact blocker policy/body. This is an additive version on the existing canonical contract, preserving recorded rejection/original-reference recovery instead of rewriting historical intent. Unsupported versions refuse. Approval remains unsupported until the outstanding sources and acceptance invariants are complete.
