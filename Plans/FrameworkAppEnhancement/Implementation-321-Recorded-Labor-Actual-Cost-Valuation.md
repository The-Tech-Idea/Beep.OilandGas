The API independently reads original CORE labor quantity/unit/employee/duty/time/audit facts, actual current order/book/budget/decision proof and complete PRODUCTION cost populations.

The screen shows original quantity/unit and UTC interval, source identity, approved amount/currency, recorded actual total and configured precision/rounding. The financial user enters an explicit rate per that exact recorded labor unit, actual valuation UTC, category, rationale and confirmation. No quantity, rate, currency conversion or date default is substituted. Omitted JSON rate/unit/currency/date facts are rejected. Amount is the recorded quantity times explicit rate, rounded only by the exact configured book rule. Already costed labor or an amount above remaining approved budget refuses.

The circuit retains the original valuation body/intent before transport; the URL retains original book, AFE, labor and intent. Unknown acknowledgement prevents replacement. Company/account/FIELD/capability changes hide values and fence late replies. Original-reference recovery and exact retry do not revalue the labor source.
