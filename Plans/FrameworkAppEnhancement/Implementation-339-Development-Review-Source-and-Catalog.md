## API flow

Paths are under `/api/field/current/development-planning`:

| Method/path | Meaning |
| --- | --- |
| GET `plans/{id}` | Exact current company/FIELD draft source |
| GET `plans/{id}/review-workflows?expectedSourceRevision=...` | Configured catalog bound to that source |
| POST `plans/{id}/review-handoffs/prepare` | Explicit source/catalog revision and selected workflow -> immutable qualified intent; no business write |
| POST `review-handoffs` | Retained original -> confirmed native initial assignment |
| POST `review-handoffs/recover` | Original -> confirmed initial/progressed graph or checked absence; no repair/write |
| GET `review-handoffs/{processId}/assigned` | Current independent recipient -> exact pending task/source and assignment metadata |
| POST `review-decisions` | Exact assigned review, intent, explicit decision and rationale -> canonical stage decision/audit/routing receipt |
| POST `review-decisions/recover` | Original decision -> checked recorded outcome or unchanged-task absence; no repair/write |
| GET `plans/{id}/review-status?expectedSourceRevision=...` | Displayed exact draft -> its current recorded review or checked absence |
| GET `review-handoffs/{processId}/history` | Current original participant -> source, ordered stage outcomes and canonical UTC history after task closure |

Authenticated app authority and independent API checks apply. Standard refusals and the shared failure reporter handle denied/stale/unavailable decision/source evidence without exposing private exception details. Existing qualified draft list/options/save/recovery routes remain canonical.
